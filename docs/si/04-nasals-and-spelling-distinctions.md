# 04: නාසික, අයෝගවාහ ලකුණු සහ ණ/න · ළ/ල · ශ/ෂ/ස අක්ෂර වින්‍යාස භේද

විෂය පථය: මෙම ගොනුව සිංහලයේ නාසික සහ නාසික ආශ්‍රිත ලකුණු ගැන සාකච්ඡා කරයි. ඒවා නම් අනුස්වාරය (ං), විසර්ගය (ඃ), චන්ද්‍රබින්දුව (ඁ), ඟ ඦ ඬ ඳ ඹ යන සඤ්ඤක අකුරු (prenasalised, "sanyaka") සහ ඞ ඤ ඥ ණ න ම යන නාසික ව්‍යඤ්ජනය. ශබ්දයෙන් පමණක් තීරණය කළ නොහැකි ණ/න, ළ/ල සහ ස/ශ/ෂ අක්ෂර වින්‍යාස භේදද මෙහි ඇතුළත්ය. එක් එක් ලකුණ යෙදිය හැකි තැන, එය උච්චාරණය වන ආකාරය සහ එක ලෙස උච්චාරණය වන අකුරු අතරින් නිවැරදි අකුර තෝරන අක්ෂර වින්‍යාස නීති මෙහි දැක්වේ. මෙම නීති බොහොමයක් පාසල් ව්‍යාකරණයෙන් සහ සංස්කෘත/පාලි නිරුක්තියෙන් පැමිණේ. අවසාන කොටස රෝමානුකරණයට සහ අක්ෂර පරිවර්තනයට (transliteration) මේවායින් ඇති වන ප්‍රතිඵල පෙන්වා දෙයි.

සම්පාදනය කළේ 2026 ඔක්තෝබර් මාසයේය. සියලු නීති මගේම වචනවලින් සාරාංශ කර ඇත. කෙටි උපුටන සලකුණු කර ඇත.

## ⚠️ ප්‍රවේශම් විය යුතු තැන් (මුලින්ම දක්වා ඇත)

රෝමානු අකුරු සහ සිංහල අකුරු අතර පෙළ පරිවර්තනය කරන, අක්ෂර වින්‍යාසය පරීක්ෂා කරන හෝ අක්ෂර වින්‍යාසය විශ්ලේෂණය කරන ඕනෑම අයෙකු සඳහා.

1. **"ng" ලිවීමට අවම වශයෙන් ක්‍රම හතරක් ඇත.** ඒවා එකිනෙක වෙනුවට යෙදිය නොහැක:
   - ං (`anusvara`): අංගය *aṃgaya* 'කොටස'
   - ඟ (`nnga`): අඟල *an̆gala* 'දිග ඒකකයක් (inch)'

9. **ඞ, ඩ සහ ඬ එක සමාන ලෙස පෙනේ.** නූතන පෙළෙහි ඞ බොහෝ විට ඩ වෙනුවට වැරදියට ලියූවකි (කොවිඩ් වෙනුවට කොවිඞ්). වචනයක මුලින් ඇති ඬ ද එසේමය (NS-048).

          or a romanization that marks prenasalisation (n̆)

1. **සඤ්ඤකය නීතියකින් නැවත ලබාගත නොහැක.** සඤ්ඤකයක්ද, ං ද, නැතහොත් නාසික + හල් + ස්පර්ශයද යන්න කිසිවකින් පුරෝකථනය කළ නොහැක (NS-033). පූර්ව නාසිකීකරණය සලකුණු නොකරන රෝමානුකරණයක් (මෙම ගොනුවේ n̆ / m̆ සම්මුතිය එය සලකුණු කරයි) මෙම වෙනස අහිමි කරයි. එවිට පරිවර්තකයට ශබ්දකෝෂයක් මත යැපීමට සිදු වේ. සඤ්ඤක කිසිදා වචන මුලට නොයෙදෙන නිසාත්, කිසිදා හල් නොගන්නා නිසාත් (NS-031), වචනයක මුල ඇති රෝමානු `ng`, `nd` හෝ `mb` ද, පසුව හල් හෝ ව්‍යඤ්ජනයක් එන `ng`, `nd` හෝ `mb` ද සඤ්ඤකයක් විය නොහැක.
2. **ං පුරෝකථනය කළ හැකි තැන්.** පහත පරිසරවලට පෙර එන නාසික + හල් ං ලෙස ලියයි:
   - k / g / kh / gh (ලංකා, බැංකුව)
   - y / r / l / v / ś / ṣ / s / h (සංවාද, සිංහ, හංස)
   - කථන ලේඛනයේ වචන අග (මං, එහෙනං)

   ඕෂ්ඨජවලට පෙර ම් ද, දන්තජවලට පෙර න් ද එලෙසම පවතී. පාලි අක්ෂර වින්‍යාසය (ඞ් / ඤ්; NS-004, NS-040) සහ විධිමත් අවසාන ම් / න් (NS-008) පිළිගත් ව්‍යතිරේකය. එබැවින් පරිවර්තකයක් එවැනි අවස්ථාවල ං බලෙන් යෙදිය යුතු නැත.
3. **මූර්ධජ ස්පර්ශවලට පෙර මූර්ධජ නාසිකය පුරෝකථනය කළ හැකිය.** `n` + `ṭ` / `ḍ` (ට ඩ) ණ් වේ (NS-055). ඉංග්‍රීසි ණය වචන සහ කථන -න්ඩ (කැලැන්ඩර්, කන්ඩ) පමණක් මෙයට ව්‍යතිරේකය. ණ්ඩ පෙරනිමි කියවීම වන අතර න්ඩ ණය වචන සහ කථන විකල්පයයි.
4. **ණත්ව නීතිය (*ṇatva*) අනිවාර්ය නීතියක් නොව, ශ්‍රේණිගත කිරීම සඳහා ඉඟියක් පමණි.** r / ṣ / ṛ ට පසු එන `n` සඳහා (ඒ අතර ඇත්තේ ස්වර, k-වර්ගය, p-වර්ගය, y, v හෝ h පමණක් නම්), වඩාත් ඉඩ ඇති අක්ෂර වින්‍යාසය ණ වේ (NS-051 සිට NS-054 දක්වා). පහත අවස්ථාවල මෙම ඉඟිය අදාළ නොවේ:
   - වචනය දේශීය වර්තමාන රූප -nawā / -na / -nu වලින් අවසන් වන විට (NS-061)
   - n සමාස මායිමක ඇති විට (NS-063)
   - වචනය ඉංග්‍රීසි ණය වචනයක් වන විට
5. **ණ සඳහා රූප විද්‍යාත්මක ඉඟි.** -iṇi / -iṇa / -uṇu / -uṇa / -uṇē (අතීත කෘදන්ත සහ කර්ම රූප) යන අවසාන රූප සහ -āṇō / -aṇi / -aṇu / -aṇḍi යන ගෞරව ප්‍රත්‍යය (NS-060, NS-061) ණ විශ්වාසදායක ලෙස පුරෝකථනය කරයි. ඒවා ප්‍රත්‍යය වගුවකට ඇතුළත් කිරීම වටී.
6. **ළ සඳහා ඉඟි.** ළ පිළිබඳ විශ්වාසදායක සලකුණු:
   - ර-ධාතුවල අතීත කාලය: kala → කළ, mala → මළ, hadāḷa (NS-071)
   - piḷi- උපසර්ගය (NS-077)
   - "කුඩා / ළාබාල" අර්ථය ඇති ḷa- වචන (NS-073)
   - සඤ්ඤකයකට කෙළින්ම පෙර එන l (NS-078)
   - l…l නාම පදයක පළමු l (NS-074)

   නිවැරදිව ලියූ පෙළක ළ්, ළ්ළ හෝ වචන අගට ණ් කිසිදා නොයෙදේ (NS-058, NS-075).
7. **රෝමානු *sh* / *s* සඳහා ඌෂ්මය තෝරා ගැනීම.**

| රෝමානු පරිසරය | වඩාත් ඉඩ ඇති අකුර | නීතිය |
|---|---|---|
| `sh` + c / ch / j / v / r, හෝ වචන මුල `shr` | ශ | NS-081, NS-082 |
| `sh` + ṭ / ṭh / ṇ, `ksh`, හෝ k / p ට පෙර i / u / e ට පසු | ෂ | NS-084, NS-085 |
| සරල `s` + t / th / n | ස | NS-087 |
| වචනයක ඌෂ්ම දෙකෙන් පළමුවැන්න | ශ | NS-083 |

   වචන මුල `sh` අපැහැදිලිය: ශ (ශ්‍රී, ශාන්ත, ශිෂ්‍ය) හෝ ෂ (ඉංග්‍රීසි ණය වචන, NS-088). එය විසඳිය හැක්කේ ශබ්දකෝෂයකින් පමණි.
8. **ඥ.** රෝමානු `gn` / `gny` / `jn` / `jny` ඥ ට අනුරූප වන්නේ ස්වරයකට පෙර පමණක් වන අතර, ශබ්දකෝෂයක් තහවුරු කරන වචනවල පමණි. සරල `gn` ග්න ද විය හැකිය (අග්නි, නග්න, ලග්න; NS-046). -ඥ / -ඥයා ප්‍රත්‍යය (විද්‍යාඥයා, නීතිඥ) ප්‍රබල ඉඟියකි.
9. **`nya` අපැහැදිලිතාව.** රෝමානු *nya* (ඤ හි අකුරු හැඳුනුම) සාමාන්‍යයෙන් නියෝජනය කරන්නේ ඉතා සුලභ න්‍ය ය (NS-047). ඤ දුර්ලභය. එබැවින් රෝමානුකරණය තාලුජ නාසිකය පැහැදිලිව සලකුණු නොකරන්නේ නම් න්‍ය වඩා ආරක්ෂිත පෙරනිමියයි.
10. **ඃ සහ ඁ.**
    - ඃ ලැබිය යුත්තේ මූලාශ්‍ර රෝමානුකරණයේ පැහැදිලි *ḥ* එකකින් පමණි. සංස්කෘත විසර්ග බොහොමයක් දැනටමත් ෝ / ර් / ශ් / ස් / ෂ් ලෙස පෙනේ (NS-022).

11. **වලංගුතා පරීක්ෂා.** නිවැරදිව ලියූ සිංහල පෙළක පහත දෑ කිසිදා අඩංගු නොවේ:
